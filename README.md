# Modern TypeScript REST API Starter 🚀

A clean, production-ready boilerplate for building scalable web services and REST APIs with Node.js, Express, and TypeScript.

## Highlights
- **Strict Typing**: 100% TypeScript with strict compiler options.
- **Request Validation**: Integrated Zod request schema validation middleware.
- **Standardized Errors**: Unified API response and error formatting.
- **Modern ESM**: Native Node.js ES modules support.

## Getting Started
```bash
git clone https://github.com/aliracabi20-web/ts-rest-api-starter.git
cd ts-rest-api-starter
npm install
npm run dev
```
